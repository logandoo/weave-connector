weave-connector — Flow Design

MCP server (stdio) giving agents persistent interactive SSH shell sessions. One SSH channel per host profile; N PTY shell sessions per channel; credentials only in config.toml, never in tool arguments (no sshpass anywhere).

Actors & Layers

MCP host (opencode agent)
  │ stdio JSON-RPC
  ▼
weave_connector.server  (FastMCP tools: ssh_*)
  ▼
weave_connector.session.Manager ── connections: profile → SSHClientConnection
  └── ShellSession ×N ── SSHClientProcess (PTY shell) + ring buffer + cursors
  ▼ SSH protocol (asyncssh)
remote sshd → bash on PTY

Primary flows

1. Open & drive a persistent shell

ssh_list_profiles → ssh_shell_open(profile, cwd?, env?)
  → bootstrap exec (cd/exports + readiness marker) → session_id
ssh_shell_exec(session_id, command, timeout_ms)
  → writes:  command; printf '\n__WC_EXIT_%s__\n' "$?"
  → pump task appends all PTY output to ring buffer (absolute cursor offsets)
  → waits on condition var for marker regex → {exit_code, output, cursor}
  → timeout → {completed:false, cursor} and marker stays pending
      ├─ ssh_shell_read(cursor, wait_ms)   incremental polling
      ├─ ssh_shell_await(session_id)       wait for pending marker → exit_code
      └─ ssh_shell_signal(interrupt)       Ctrl-C; marker survives (same-line form)

2. Interactive / TUI

ssh_shell_write(session_id, data | data_base64)  raw bytes, no marker
ssh_shell_read(session_id, cursor, wait_ms)      screen text, ANSI-stripped
ssh_shell_resize(session_id, cols, rows)         SIGWINCH via change_terminal_size

3. Teardown

ssh_shell_close(session_id)   session only
ssh_disconnect(profile)       all sessions + the SSH channel
idle reaper                   closes sessions idle > idle_timeout_sec

Credential flow (password_ref)

config.toml [profiles.x] password_ref = "keychain:svc/acct" | "env:VAR"
  → ssh_connect/open_shell → SecretResolver.resolve (in-process, fail-closed)
  → register_secret (scrub table) → asyncssh.connect(password=...)
  → audit.jsonl line (ref+profile+host+ok, never value)
  → all shell output passes scrub_text() before returning (best-effort: raw/hex/b64/b64url,
     PTY-wrap tolerant; fragments at window edges trimmed; transformed values out of scope)

Key design decisions

  • Marker-based completion: exit codes without extra channels; single-line ; printf MARKER $? survives Ctrl-C (tty input-queue flush would eat a queued line).
  • Cursor stream: absolute byte offsets over a capped ring buffer; data_loss flagged when the cursor fell behind the retained window.
  • One pending exec per session — shell stdin is single; concurrent execs are rejected with a clear error.
  • Security: profiles in config.toml (chmod 600); list/status tools return public fields only; accept_unknown_host=true reserved for lab targets.
